Install PRYN on Linux.
One guide. Every supported route.

These instructions install the prebuilt x86_64 executable. You do not need Rust, Cargo, a compiler, glibc or shared runtime libraries. Choose the section for your distribution.

1. Before you install

  • Architecture: the v0.1.1 prebuilt release supports x86_64 / amd64 only. ARM64 / aarch64 is not available yet.
  • Internet: you need access to GitHub Releases to download the files.
  • Privileges: installing a system package needs administrator privileges. Running PRYN does not.
  • Runtime: the prebuilt executable is static. Rust, Cargo, a compiler, glibc and shared runtime libraries are not required.
  • Package trust: release assets include SHA-256 checksums, but are not cryptographically signed. The RPM is unsigned. Read the checksum and trust note before installing.
uname -m

The expected output is x86_64. If your system reports aarch64, the prebuilt release is not for your machine.

2. Ubuntu, Debian, Kali and derivatives

Use the amd64 .deb package. The current release asset is pryn_0.1.1_amd64.deb.

curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn_0.1.1_amd64.deb
sudo apt install ./pryn_0.1.1_amd64.deb

APT installs the local package file. This does not add a PRYN APT repository. The command sudo apt install pryn without a local file will not work from the default Ubuntu/Debian repositories.

Automated container smoke tests passed on Ubuntu 26.04, Debian 13 and Kali Rolling. Linux Mint and Pop!_OS are intended compatible derivatives, but have not been individually tested.

3. Fedora and RPM distributions

Use pryn-0.1.1-1.x86_64.rpm. The RPM is unsigned, so DNF must skip signature verification for this specific local file.

curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn-0.1.1-1.x86_64.rpm
sudo dnf install --nogpgcheck ./pryn-0.1.1-1.x86_64.rpm

Only use the file from the official PRYN release and verify its SHA-256 checksum first. Fedora is the automated RPM smoke-test target. Rocky Linux, AlmaLinux and RHEL are intended RPM-family targets, not individually validated yet.

4. openSUSE

The same x86_64 RPM is the intended local package. openSUSE is not yet in the automated smoke-test matrix.

curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn-0.1.1-1.x86_64.rpm
sudo zypper install --allow-unsigned-rpm ./pryn-0.1.1-1.x86_64.rpm
The RPM is unsigned. The command allows this local RPM to be installed without a package signature. Verify the file checksum and confirm that you trust the release source before continuing.

5. Arch Linux

The release includes a generated PKGBUILD for pryn-bin. The -bin suffix is the Arch convention for a package that installs a prebuilt binary. It installs the executable named pryn.

AUR status: not published yet. The command yay -S pryn-bin will work only after the package is submitted and appears in the AUR. Until then, build the local package as shown below.

Install and build the local package

sudo pacman -S --needed base-devel curl
mkdir -p ~/build/pryn-bin
cd ~/build/pryn-bin

curl -fL https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn-bin.PKGBUILD -o PKGBUILD

makepkg --printsrcinfo > .SRCINFO
makepkg --verifysource
makepkg -si

This uses makepkg to package the precompiled executable. It does not compile PRYN from Rust source and does not need Cargo. The PKGBUILD pins the SHA-256 of the corresponding release archive.

After AUR publication

yay -S pryn-bin

The package name remains pryn-bin; the command users run after installation remains pryn.

See the ArchWiki AUR submission guidelines for the package repository and maintenance rules.

6. Alpine and other compatible x86_64 Linux

Use the generic static-musl archive: pryn-v0.1.1-x86_64-unknown-linux-musl.tar.gz.

curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn-v0.1.1-x86_64-unknown-linux-musl.tar.gz
tar -xzf pryn-v0.1.1-x86_64-unknown-linux-musl.tar.gz
mkdir -p "$HOME/.local/bin"
install -m 755 pryn-v0.1.1/pryn "$HOME/.local/bin/pryn"
"$HOME/.local/bin/pryn" --version

Make sure $HOME/.local/bin is on your PATH. If it is not, add the following line to your shell startup file:

export PATH="$HOME/.local/bin:$PATH"

The archive passed an Alpine container startup smoke test. Alpine's physical hardware and service integration has not been validated on a physical Alpine machine.

7. Verify the download and run PRYN

Download SHA256SUMS beside the package or archive you downloaded, then check the files in the current directory:

curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/SHA256SUMS
sha256sum --ignore-missing --check SHA256SUMS

A checksum detects accidental corruption. Because the checksum file and package are hosted in the same release, it does not independently prove who published them. Cryptographic release signatures and signed package repositories are deferred.

Check the installation

pryn --version
pryn --help
pryn check
pryn check wifi
pryn check bluetooth
pryn check audio

PRYN does not need sudo to run its supported checks. Exit code 1 means the diagnostic report contains a warning, problem, unknown, partial or unimplemented result. It does not necessarily mean that the program crashed.

8. Update and uninstall

For a future release, download the matching versioned package or archive from the GitHub Releases page, verify its checksum, and install it over the existing version using the same package-manager command.

Direct-download DEB and RPM packages do not update automatically. PRYN does not operate a hosted APT or RPM repository yet.
