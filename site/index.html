02 / INSTALLATION

Pick your distro.
Get the right package.

One x86_64 executable. Native package wrappers where available. A generic static archive everywhere else.

RELEASE 0.1.1
.DEB PACKAGECI SMOKE-TESTED

Debian, Ubuntu & Kali

Install the local amd64 package with APT. No Rust toolchain, compiler, or shared runtime libraries required.

pryn_0.1.1_amd64.debDebian package · x86_64
↓
INSTALL COMMAND
curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn_0.1.1_amd64.deb
sudo apt install ./pryn_0.1.1_amd64.deb

Direct package install only. This does not add a PRYN APT repository.

.RPM PACKAGEFEDORA CI-TESTED

Fedora & RPM family

Install the x86_64 RPM locally. The current package is unsigned, so DNF must skip signature verification for this file.

pryn-0.1.1-1.x86_64.rpmRPM package · x86_64 · unsigned
↓
FEDORA / DNF
curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn-0.1.1-1.x86_64.rpm
sudo dnf install --nogpgcheck ./pryn-0.1.1-1.x86_64.rpm
OPENSUSE / ZYPPER
sudo zypper install --allow-unsigned-rpm ./pryn-0.1.1-1.x86_64.rpm

Fedora is the CI-tested RPM target. openSUSE and RHEL derivatives are intended targets, not yet individually validated.

ARCH PACKAGE RECIPEAUR SUBMISSION PENDING

Arch Linux

A PKGBUILD is included in the release. Build a local package around the precompiled binary; Cargo is not involved.

pryn-bin.PKGBUILDLocal makepkg recipe · x86_64
↓
BUILD & INSTALL LOCALLY
sudo pacman -S --needed base-devel curl
mkdir -p ~/build/pryn-bin && cd ~/build/pryn-bin
curl -fL https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn-bin.PKGBUILD -o PKGBUILD
makepkg --printsrcinfo > .SRCINFO
makepkg --verifysource
makepkg -si
Why not yay yet?The recipe has not been submitted to the AUR. yay -S pryn-bin will work only after the package is published and searchable.
STATIC MUSL ARCHIVEALPINE CI-TESTED

Alpine & other x86_64 Linux

The universal archive contains the same static executable. Extract it and install it in your user bin directory.

pryn-v0.1.1-x86_64-unknown-linux-musl.tar.gzGeneric Linux archive · x86_64
↓
EXTRACT & INSTALL
curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/pryn-v0.1.1-x86_64-unknown-linux-musl.tar.gz
tar -xzf pryn-v0.1.1-x86_64-unknown-linux-musl.tar.gz
mkdir -p "$HOME/.local/bin"
install -m 755 pryn-v0.1.1/pryn "$HOME/.local/bin/pryn"

Ensure ~/.local/bin is on your PATH. Alpine container startup passed; physical Alpine hardware integration is not yet validated.
