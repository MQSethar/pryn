01 / INSTALLATION

Get PRYN running.

Choose your Linux family. Download one file, then run the install command. You do not need Rust or Cargo.

x64 One requirement: Linux on an x86_64 / amd64 machine. Check with uname -m. ARM64 is not supported yet.

RPM PACKAGE

Fedora & RPM systems

One x86_64 package for Fedora and compatible RPM systems.

Fedora container tested
1

pryn-0.1.1-1.x86_64.rpmDownload .rpm ↓
2
Install it on FedoraThe current RPM is unsigned, so DNF skips signature verification for this local file.
cd ~/Downloads && sudo dnf install --nogpgcheck ./pryn-0.1.1-1.x86_64.rpm
Using openSUSE instead?

Download the same RPM above, then run:

cd ~/Downloads && sudo zypper install --allow-unsigned-rpm ./pryn-0.1.1-1.x86_64.rpm
openSUSE is an intended target, not yet included in the CI smoke tests.

The RPM is unsigned. Only install it if you trust the release source and have checked the checksum.

ARCH PACKAGE RECIPE

Arch Linux

Build a local pacman package around the prebuilt binary. No Rust compilation.

AUR submission pending
1
Download the PKGBUILDSave the recipe to your Downloads folder.
pryn-bin.PKGBUILDDownload PKGBUILD ↓
2
Build and installFirst install Arch's standard package build tools.
sudo pacman -S --needed base-devel mkdir -p ~/build/pryn-bin cp ~/Downloads/pryn-bin.PKGBUILD ~/build/pryn-bin/PKGBUILD cd ~/build/pryn-bin makepkg --printsrcinfo > .SRCINFO makepkg --verifysource makepkg -si

The PKGBUILD downloads the static release archive and verifies its pinned SHA-256 checksum. It does not build PRYN from source.

PRYN is available in the AUR.

Install the community package with your AUR helper.

RELEASE 0.1.1LINUX x86_64All release files ↗
Want to verify the download?

Download the checksum file, then run this in your Downloads folder. It verifies any PRYN release files you downloaded.

cd ~/Downloads && curl -fLO https://github.com/MQSethar/pryn/releases/download/v0.1.1/SHA256SUMS && sha256sum --ignore-missing --check SHA256SUMS

Checksums detect accidental corruption. The current release assets are not cryptographically signed, so a checksum from the same GitHub release is not independent proof of publisher identity.

02 / WHAT IT CHECKS

Three systems. One report.

PRYN gathers what Linux exposes and keeps facts separate from assumptions.

Wi-Fi

Interfaces, drivers, radio state, NetworkManager or iwd, IP addresses, routes and DNS configuration.

Bluetooth

Controllers, radio blocks, BlueZ, adapter power, paired devices and connection state.

Audio

ALSA cards, PipeWire/PulseAudio endpoints, defaults, mute, volume, ports and profiles.

03 / BUILT TO BE SAFE
