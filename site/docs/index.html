GET STARTED

Run your first check

Open a terminal and run PRYN as your normal user. It does not need root privileges for its supported checks.

pryn check

To inspect one area:

Wi-Fipryn check wifipryn check wifi
Bluetoothpryn check bluetoothpryn check bluetooth
Audiopryn check audiopryn check audio

For more detail or machine-readable output:

pryn check --verbose pryn check --format json

THE SHORT VERSION

Observe. Evaluate. Report.

1. Observe

PRYN reads Linux interfaces and available service state through system files, D-Bus and audio protocols.

2. Evaluate

Diagnostic rules compare those observations with explicit conditions. Collection and interpretation remain separate.

3. Report

The same report can be displayed as readable terminal text or JSON.

Missing or contradictory information stays visible. PRYN does not turn missing evidence into a green result.

READ THE REPORT

What the result labels mean

PASS

The check completed and its stated condition was observed.

WARNING

A relevant condition was observed, but it does not prove a root cause.

PROBLEM

The available evidence supports a specific failure condition.

UNKNOWN

Evidence was unavailable, inaccessible or not strong enough to decide.

NOT APPLICABLE

The check does not apply to this machine or provider.

NOT IMPLEMENTED

The check is not implemented in this version. A subsystem can therefore be partial.

Exit codes

  • 0 — the report contains no warning, problem, unknown, partial or unimplemented result.
  • 1 — the report was created, but contains one of those results. This is a diagnostic outcome, not necessarily a crash.
  • 2 — PRYN could not parse or execute the command, or could not write the report.

01 / WI-FI

What PRYN checks about Wi-Fi

PRYN inspects discovered wireless interfaces, their drivers and radio state. When available, it reads NetworkManager or standalone iwd state and checks local IP addresses, default routes and configured DNS nameservers.

Important: a connected Wi-Fi interface does not prove that the internet works. PRYN does not send ping, DNS or HTTP probes. NetworkManager's connectivity value may be old and system-wide.

02 / BLUETOOTH

What PRYN checks about Bluetooth

PRYN inspects controller presence, radio blocks, BlueZ availability, adapter power, paired devices and reported connection state.

Important: a paired device is not necessarily connected. PRYN does not start discovery, pair devices or connect/disconnect them.

03 / AUDIO

What PRYN checks about audio

PRYN inspects ALSA cards and the current user's PulseAudio-compatible audio service. If pw-dump is available, it can also inspect the native PipeWire graph.

It can report default output and input devices, mute and volume levels, channels, sample formats, ports and exposed card profiles.

Important: PRYN does not play test sounds or record microphone audio. A configured output does not prove sound is physically audible; a capture source does not prove that a microphone records intelligible audio. A suspended endpoint is normally idle, not broken.

PRIVACY AND SAFETY

What PRYN does not do

  • It does not change network, Bluetooth or audio settings.
  • It does not restart services, pair devices, start Bluetooth discovery or perform repairs.
  • It does not collect telemetry or make PRYN-initiated network requests.
  • It does not collect Wi-Fi passwords, SSIDs, MAC addresses, journal contents, application stream names or microphone recordings.

Reports can include local IP addresses, default gateways and DNS server addresses. Review JSON output before sharing it publicly.

FOR DEVELOPERS

How the code is organised

PRYN is a modular monolith: one executable, one process and shared diagnostic models. The CLI coordinates the app, platform collectors return typed observations, diagnostic rules evaluate those observations, and report renderers produce terminal text or JSON.

Collectors do not decide whether a state is a fault. Diagnostic rules do not perform system I/O. This separation keeps data collection, interpretation and presentation independently testable.
