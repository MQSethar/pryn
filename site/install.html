DEB PACKAGE

Debian, Ubuntu, Kali and derivatives

Use this package on Debian-based systems. Linux Mint and Pop!_OS are expected to be compatible, but have not been separately tested.

Container-tested
1

Download the package

Save this file in your Downloads folder.

pryn_0.1.1_amd64.debDownload .deb ↓
2

Install it

This uses the file you just downloaded.

cd ~/Downloads && sudo apt install ./pryn_0.1.1_amd64.deb

CI installation tests passed on Ubuntu 26.04, Debian 13 and Kali Rolling.

Download the newer .deb

Use the button below to download the latest release. Then run the same APT command to install it over the older version.

pryn_0.1.1_amd64.debDownload latest .deb ↓
cd ~/Downloads && sudo apt install ./pryn_0.1.1_amd64.deb

APT replaces the installed PRYN package when the downloaded package has a newer version. Direct downloads do not update automatically.

Remove PRYN

This removes PRYN but keeps its configuration files, if any.

sudo apt remove pryn

ARCH PACKAGE

Arch Linux

The AUR package is not published yet. For now, install the prebuilt binary with the maintained PRYN PKGBUILD. No Rust compilation is involved.

AUR pending

Download the package recipe

Save the PKGBUILD file in Downloads.

Build and install

Arch's standard build tools are needed. PRYN itself is not compiled from source.

sudo pacman -S --needed base-devel mkdir -p ~/build/pryn-bin cp ~/Downloads/pryn-bin.PKGBUILD ~/build/pryn-bin/PKGBUILD cd ~/build/pryn-bin makepkg -si

Download the new PKGBUILD

Download the latest PKGBUILD, replace the old file in ~/build/pryn-bin, then build and install the update.

pryn-bin.PKGBUILDDownload latest PKGBUILD ↓
cp -f ~/Downloads/pryn-bin.PKGBUILD ~/build/pryn-bin/PKGBUILD cd ~/build/pryn-bin makepkg -si

Remove PRYN

Pacman removes the locally installed package.

sudo pacman -Rns pryn-bin

The recipe verifies the GitHub release archive with a pinned SHA-256 checksum before packaging it.

ALTERNATIVE METHOD

Install through Cargo

Use this if you already work with Rust. Cargo downloads the crate and compiles PRYN on your machine. This is not the prebuilt-binary route.

Requires Rust + Cargo

Install

Install the published crate.

cargo install pryn --locked

Update

Replace the installed version with the latest crates.io release.

cargo install pryn --locked --force

Remove

Uninstall the Cargo-managed executable.

cargo uninstall pryn

Check that it works

After installation, run PRYN as your normal user. These checks do not need sudo.

pryn --version && pryn check

Before you go

Choose one installation method and use the matching update and remove instructions. For example, remove a Cargo install with cargo uninstall, not with APT or pacman.

The current RPM is unsigned. The release includes SHA-256 checksums, but these are not a cryptographic publisher signature. PRYN does not install or enable NetworkManager, iwd, BlueZ, PipeWire or other host services; those remain optional.
