# Arch package: `pryn-bin`

`pryn-bin` is the AUR package name for the prebuilt static-musl PRYN binary. The package installs the executable at `/usr/bin/pryn`; users run `pryn`, not `pryn-bin`.

The v0.1.1 recipe and metadata are attached to the [GitHub release](https://github.com/MQSethar/pryn/releases/tag/v0.1.1). The package has **not** been submitted to the AUR yet. Do not advertise `yay -S pryn-bin` as available until <https://aur.archlinux.org/packages/pryn-bin> exists.

See [`docs/aur-submission.md`](../../docs/aur-submission.md) for the complete maintainer workflow: account and SSH setup, clean PKGBUILD validation, initial upload, post-publication testing and future updates.
