# PRYN

Evidence-based Linux system diagnostics.

PRYN helps users understand and diagnose common Linux system
problems through structured observations, diagnostic rules,
and actionable recommendations.

## Initial scope

- Wi-Fi diagnostics
- Bluetooth diagnostics
- Audio diagnostics

- Rust toolchain specified in rust-toolchain.toml

- Linux development tools
